# 📚 کتابستان — فروشگاه آنلاین کتاب

پروژه پایانی کاردانی — فروشگاه آنلاین کتاب با سیستم پیشنهاد هوشمند

---

## 🎯 معرفی پروژه

«کتابستان» یک فروشگاه آنلاین کتاب است که با فریم‌ورک **Laravel** ساخته شده. این پروژه شامل بخش‌های زیر است:

- 🏠 **صفحه اصلی** با قفسه سه‌بعدی کتاب‌ها
- 📚 **فروشگاه** با فیلتر ژانر و جستجو
- ✍️ **پروفایل نویسندگان** با زندگی‌نامه، جملات و اطلاعات کامل
- 🛒 **سبد خرید** و فرآیند پرداخت
- 👤 **پنل کاربری** (پروفایل، سفارش‌ها، مرجوعی‌ها، نظرات، پیام‌ها)
- 👑 **پنل ادمین** (مدیریت کتاب‌ها، نویسندگان، کاربران، سفارش‌ها، نظرات، پیام‌ها، مرجوعی‌ها)
- 🔍 **جستجوی سراسری** (کتاب‌ها + نویسندگان)
- 🤖 **سیستم پیشنهاد** بر اساس ژانر و نویسنده
- 💬 **سیستم نظرات** با امتیازدهی
- 📩 **پشتیبانی** با قابلیت پاسخ ادمین

## ⚙️ نصب و راه‌اندازی

### پیش‌نیازها
- PHP >= 8.3
- Composer
- MySQL >= 8.0
- Node.js (اختیاری — پروژه از Vite استفاده نمی‌کند)

### مراحل نصب

```bash
# ۱. کلون کردن پروژه
git clone <repository-url>
cd bookstore

# ۲. نصب پکیج‌ها
composer install

# ۳. کپی فایل env
cp .env.example .env

# ۴. تنظیم دیتابیس در .env
# DB_CONNECTION=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=bookstore
# DB_USERNAME=root
# DB_PASSWORD=

# ۵. ساخت کلید
php artisan key:generate

# ۶. اجرای migration و seeder
php artisan migrate:fresh --seed

# ۷. اجرای سرور
php artisan serve
